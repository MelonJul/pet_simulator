# Event cat pose assets — group C

Generated with the built-in `image_gen` tool on 2026-10-21. No API/CLI fallback, no pixel edits, no image manipulation. Project PNG files are byte-for-byte copies of the selected generated originals. Python/Pillow was used only for read-only dimensions/alpha/bounds inspection and writing JSON source-rectangle metadata.

## Atlas contract

Three characters: `catSocial` (솜이), `catSensitive` (미루), `catQuiet` (율무). Each selected PNG is 1536 × 1024 RGBA with alpha range 0–254. There are eight separate poses, ordered left to right, top row then bottom row: curious reaching; startled recoil; stretching scratch; content loaf; timid peek; cautious sniff; low-energy curl; clinic-wary seated.

Use the matching `*-events-v1.json` file's eight `frames` arrays (`[x,y,width,height]`) instead of uniform tile cropping. Every rectangle contains the whole matching visible character with a small transparent padding. Every source image's visible alpha >128 lies within the union of the eight supplied frames. The generated geometry is deliberately preserved; the game can fit these source rectangles into a virtual frame and align feet. No deliberate diagnosis, injury, props or medical treatment is portrayed.

Visual review confirmed individual coat identity, whole-body separate poses, changing eyes/eyelids, ear positions, paws and posture. The blue-gray cat retains its white muzzle, chest, socks and tail tip; the cream cat retains chocolate ears, face mask, paws and tail; the white cat retains fluffy white fur. Fully closed content eyelids read as a slow blink rather than an open-eyed expression.
