# 처음, 함께 — 반려생활 7일 · 4.0.0

입양 전 60초 홈쇼핑 → 7일 돌봄 → 기록 기반 최종 평가까지 플레이하는 한국어 HTML5 게임입니다. HTML/CSS/JavaScript와 로컬 이미지로 동작하며, 게임 실행에 외부 API·회원가입·백엔드·데이터베이스가 필요 없습니다.

## 실행

- Windows에서 `start.cmd`를 더블클릭하거나 `dist/index.html`을 브라우저에서 엽니다. `dist`의 파일과 `assets` 폴더를 함께 유지하세요.
- 동일 주소에서 안정적으로 저장하려면 Node.js가 설치된 환경에서 `node preview.mjs`를 실행하고 `http://127.0.0.1:4173/`에 접속합니다. 종료는 Ctrl+C입니다. 이 서버는 파일만 전달하며 게임 계산이나 데이터를 처리하지 않습니다.
- 정적 호스팅에는 `dist/` 전체를 올립니다. 기존 Sites 배포는 소유자 전용 접근 정책을 유지합니다. 게임 자체에는 회원가입이 없습니다.

## 4.0 — 동작과 두 가지 게임 모드

- 시작 화면에서 **7일치 시뮬레이션** 또는 **돌발 상황 체험**을 선택합니다. 체험에는 5개 챕터와 종에 맞는 사건 카드가 있으며 잠금 없이 직접 고를 수 있습니다. 도입 → 동작 → 전체 화면 → 설명/대응 → 결과 → 다시 체험/다음 사건/목록으로 이어집니다.
- 급여는 실제 그릇 위치에 입을 맞춰 이동·자리 잡기·고개 내리기·먹기·마무리 순으로 진행합니다. 개/고양이의 고개 높이와 입·혀 움직임을 구분하고 사료 감소/물결을 표시합니다. 로컬 원본 그림을 머리·몸·앞발 레이어로 표시하며 새 외부 의존성은 없습니다.
- 물 교체는 행동 1회로 자동 음수까지 이어집니다. 실제 마신 경우에만 물 재고와 수분을 반영합니다. 불안 등으로 마시지 않으면 거부를 기록하고 음수 성공 모션을 재생하지 않습니다.
- 일반 소변은 아침 식사 뒤, 대변은 점심 식사 뒤에 연출합니다. 고양이는 화장실과 모래 덮기, 개는 개체별 쪼그리기/다리 들기를 구분합니다. 흔적은 청소 전까지 방과 저장에 남습니다. 이 주기는 실제 생리 주기와 관계없는 게임 규칙입니다.
- 대변·소변 교육은 각각 모드별 최초 한 번만 표시합니다. 새로고침/재체험으로 초기화되지 않으며 새 시뮬레이션 또는 체험 목록의 기록 초기화로 다시 시작합니다.
- 이벤트 설명은 **무슨 일이 있었나요? → 왜 이런 행동을 했을까요? → 지금 할 대응을 골라 주세요** 세 항목입니다. 무료 선택지는 0원/0회 표시를 생략하고 대응 결과는 피드백과 일지에 남깁니다.
- 일반·돌발 사건 목표는 하루 2~3회입니다. 식사·돌봄·시간 전환에서 판단하며 모든 모션/사건은 대기열로 순서대로 표시합니다. 일반 배변 교육은 빈도와 대응 점수에서 제외합니다. 위험 신호가 강하면 기본 돌봄 기회를 먼저 줍니다. 조건을 만족하는 심각 사건의 별도 추첨은 하루 한 번입니다.
- 효과는 명령 때 한 번, 동작 완료는 고유 번호로 한 번만 기록합니다. 모션 중 클릭을 막고 새로고침 뒤에는 저장된 동작을 이어 보여주며 사료·행동·회복을 다시 적용하지 않습니다.

모드/챕터/동작/저장 구조와 수정 지점은 [MODES.md](MODES.md)에 있습니다.

## 3.4 — 클릭해서 보는 상태와 상점 가격

- 방 안의 반려동물 또는 `이름 · 상태 보기`를 누르면 상태창이 열립니다. 식사·수분·청결·활동·건강·친밀도·스트레스·피로 8개 지표와 현재 행동·표정·실제 음수 기록을 함께 표시합니다. 스트레스·피로는 낮을수록 편안합니다. 관찰과 열람은 무료이고 관찰 문장만 일지에 기록합니다.
- 오전과 오후 각각 행동 2회로 고정합니다. 기존 3/4회 설정 저장도 이미 사용한 행동을 빼고 최대 2회로 조정합니다. 불러오기를 반복해도 횟수가 복구되지 않습니다.
- 상점 32종은 2026-10-21에 조회한 국내 판매가를 참고합니다. 상품별 `가격 근거 보기`에서 비교 상품, 실제 포장 크기, 표시 판매가, 게임 환산 기준, 판매처 링크를 확인합니다. 별도 배송비·회원가·쿠폰은 제외하며 공개 즉시할인은 포함합니다. 캐시·검색 색인·품절 상품의 가격도 있어 당일 결제 가격이나 전국 평균을 의미하지 않습니다.
- 패드와 배변봉투는 10장으로 환산합니다. 사료·간식·모래 등의 사용 횟수는 게임 단위이며 실제 권장 사용량이 아닙니다. 사료 공통 기준가는 개 사료 1kg 9,610원과 고양이 사료 1.5kg 11,590원의 중간값 10,600원입니다. 특정 사료를 모든 개체에 급여하라는 의미는 아닙니다.
- 가격은 `dist/price-data.js`에서 관리하며 게임 시작 때 `prices`에 저장합니다. **새 가격은 새 게임부터 적용**합니다. 이전 저장은 당시 가격으로 장바구니 환불과 추가 주문을 계산해 잔액·기록을 보존합니다. 추가 주문은 해당 게임의 기준가 × 1.10으로 유지합니다.
- 기본 예산은 20만 원을 유지합니다. 비싼 선택 물품을 전부 살 필요 없이 적절한 놀이와 필수 돌봄을 제공하면 17마리 모두 7일을 마칠 수 있습니다.

## 3.3 — 선택한 고양이의 상황별 표정과 움직임

3.3.1에서는 방에 설치 물품 7종(밥그릇·물그릇·쉼터·화장실·스크래처·캣타워·숨숨 하우스)만 표시합니다. 사료·간식·모래·위생용품·휴대 장난감·이동장·산책 도구는 인벤토리에 보관합니다. 쇼핑 미리보기와 추가 구매·이어하기에도 동일하게 적용합니다. 설치 물품도 인벤토리에서 보유 상태를 확인할 수 있으며, 방 꾸미기로 이동할 수 있는 것은 설치 물품뿐입니다. 분류는 `dist/data.js`의 `ROOM_ITEMS`와 각 물품의 `placement`에서 관리합니다.

두둥이를 포함한 고양이 9마리에 각각 8종, 총 **72개의 상황용 표정·자세**를 추가했습니다. 모든 고양이 사건과 공통 사건에 선택한 개체를 표시합니다. 컵은 앞발 탐색→놀라 물러남→살피기, 소파는 몸을 늘여 긁기, 상자는 편안한 눈과 웅크린 자세, 손님은 낮게 숨어 내다보기처럼 반응을 구분했습니다. 나이·민감도에 따라 움직임 강도가 달라집니다.

짧은 반응 뒤에도 캐릭터와 그림은 계속 보이며 닫기를 눌러야 설명으로 넘어갑니다. 제목을 화면 아래로 옮기고 모바일에서 캐릭터를 확대했습니다. 심각한 식사·수분·건강 신호는 사건 연출보다 우선하며, 모션 감소 설정에서는 마지막 표정을 정지 상태로 표시합니다. 선택한 고양이와 배경 로딩이 끝나야 연출이 시작됩니다. 시각 연출은 게임 시간이나 상태를 바꾸지 않습니다.

이미지는 내장 `image_gen`으로 생성한 로컬 PNG입니다. 생성 원본은 수정하지 않고 `dist/assets/events/pets/*-events-v1.json`의 포즈 영역을 CSS로 표시합니다. 제작 프롬프트와 원본 위치는 `ASSET-PROMPTS-EVENT-CATS-A.md`, `-B.md`, `-C.md`에 있습니다.

## 상황 이미지와 교육 안내

기존 16개와 새 14개를 합해 30개 상황 정의를 제공합니다. **게임 → 전체 화면 상황 이미지 → 닫기 → 상황·가능한 이유·대응 선택 → 게임** 순서입니다. 이미지의 닫기는 게임 복귀가 아니라 설명으로 이동합니다. 전체 화면과 설명을 읽는 동안 상태·날짜·자동 움직임은 멈추고 배경은 조작할 수 없습니다.

4개의 로컬 그림 아틀라스(총 16개 장면)에 선택한 반려동물을 배치합니다. 고양이는 사건 전용 포즈, 개는 기존 8개 상태 포즈와 사건별 움직임을 사용합니다. 두둥이 포함 17마리의 종·털색·체형을 유지합니다. 컵의 플라스틱/유리 재질, 파손·청소·사용 중지 결과를 구분합니다. 이미지·규칙·문구·비용·빈도는 `dist/event-data.js`에서 수정합니다. 상세 구조와 추가 방법은 `EVENTS.md`, 배경 이미지 프롬프트는 `ASSET-PROMPTS-EVENTS.md`에 있습니다.

사건과 대응은 고유 사건 번호로 한 번씩만 반영합니다. 이미지/설명 단계 모두 저장되며, 일지의 **사건 설명·대응 다시 읽기**는 읽기 전용입니다. 대응의 물품·비용·행동을 미리 표시하며 무료 환경 조정도 만점을 받을 수 있습니다. 병원비와 가정용 물건 교체비는 특별 지출의 별도 유형으로 기록하고, 돌봄 물품 추가 주문은 기존 기준가 × 1.10입니다.

## 3.1 — 두둥이 추가

사진 속 **두둥이 · 코리안 숏헤어 · 6살**을 추가했습니다. 짙은 고등어무늬와 연두빛 눈을 기존 봉제인형 화풍에 반영했습니다. 이름·품종·나이·외형 이외의 성격, 선호와 건강 수치는 게임용 설정이며 사진으로 추정한 실제 정보가 아닙니다. 새 게임의 기본 선택은 두둥이이며 기존 저장은 그대로 이어집니다. 추가 이미지의 정확한 프롬프트는 `ASSET-PROMPT-DUDUNG.md`에 있습니다.

## 주요 기능

- **17마리**: 개 8마리·고양이 9마리. 어린 개체·성체·노령 개체의 나이, 건강 관리 사항, 활동량, 적응 속도, 성격, 습관과 취향이 다릅니다.
- **136개 표정·자세**: 개체마다 평온, 배고픔, 수분 부족, 놀이 욕구, 만족, 졸림, 불안, 불편함의 8개 모습을 생성했습니다. 심한 상태는 움직임도 작고 낮아지며 놀이 동작보다 우선 표시합니다.
- **관찰과 일지**: 무료 관찰로 식사·음수·자세·표정을 확인합니다. 시간대별로 행동 → 반응 → 확인한 변화를 자동 기록합니다. 관찰하지 않은 상태 변화는 미확인으로 남깁니다.
- **인벤토리**: 방 아래 가로 물품 목록을 없애고 가방 버튼과 분류별 격자 슬롯으로 바꿨습니다. 물품을 선택하면 용도·수량·사용 조건·행동 비용과 사용 불가 이유를 보여줍니다.
- **개체별 놀이**: 공 쫓기/물어오기, 터그 당기기, 삑삑 소리 듣기/놀라기, 낚싯대 덮치기, 인형 안기/옮기기, 퍼즐 탐색 등 동작을 구분했습니다. 반응은 성격·종·나이·건강 변화·피로·스트레스·반복 사용을 반영합니다.
- **조기 종료**: 식사 또는 수분 중 하나라도 0이 되면 즉시 종료합니다. 종료 원인·날짜·시간대·관련 기록·개선할 행동을 보여주며 재접속해도 종료 상태를 유지합니다.

기존 홈쇼핑, 물품 자동 배치·방 꾸미기, 고정 110% 추가 주문, 가이드북, 7일 최종 평가를 유지했습니다. 상품은 32종입니다. 생성 이미지 원본과 제작 프롬프트를 함께 제공합니다.

## 플레이 흐름

1. 종 탭에서 개 8마리 또는 고양이 9마리 중 한 마리를 선택하고 알려진 관리 사항을 확인합니다. 세부 장난감 취향은 플레이하며 발견합니다.
2. 기본 20만 원·60초 안에 준비물을 고릅니다. 예산·제한시간은 시작 화면의 진행 설정에서 조절합니다. 행동은 오전·오후 각각 2회로 고정합니다. 가이드북이나 가격 출처를 읽는 동안 쇼핑 시간은 멈춥니다.
3. 아침 급여 → 오전 돌봄 → 점심 급여 → 오후 돌봄 → 저녁 급여 → 하루 결산 순서로 진행합니다.
4. 방의 친구 또는 **관찰하기**를 눌러 신호를 확인합니다. **인벤토리**에서 필요한 물품을 선택하고 사용합니다. 방에 놓인 물건에서도 같은 행동을 할 수 있습니다.
5. 새 물 준비와 실제 음수를 각각 확인합니다. 물 교체 뒤 자동으로 마시는 모습을 보여주며 실제 음수에만 수분이 회복됩니다.
6. 일지에서 지난 기록과 취향 발견을 살펴보고 다음 날 돌봄을 조정합니다. 7일을 완료하면 항목별 점수와 비용·잘한 선택·개선할 선택을 확인합니다.

## 행동과 자원 규칙

| 행동 | 비용과 효과 |
|---|---|
| 정량 급여 | 사료 1끼, 행동 횟수 없음. 식사 +26 후 급여 시간 소모 적용 |
| 2끼분 급여 | 사료 2끼, 과다 급여 기록. 정량 식사로 계산하지 않음 |
| 식사 건너뛰기 | 식사 −12 후 시간 소모. 기록·평가에 반영 |
| 부족한 식사 보충 | 식사 30 이하에서 경고 버튼 제공. 사료 1끼, 식사 +26. 예정된 식사와 별도 기록 |
| 물 교체 + 음수 | 물그릇 필요, 행동 1회. 새 물 3회분 준비 후 자동으로 실제 음수 시도 |
| 실제 음수 | 별도 버튼 없음. 마시면 물 1회분 감소, 개체별 수분 +28~32. 심하게 불안하면 거부 가능 |
| 배변 처리 | 행동 1회, 청소용품 1회분 + 개의 패드 1장 / 고양이의 모래 1회분. 고양이는 화장실 필요 |
| 놀이 | 행동 1회. 보유한 장난감과 강도를 선택. 장난감은 반복 사용 |
| 산책 | 개만 제공. 행동 1회, 하네스 필요·봉투 1장 소모. 개체의 활동 필요량에 맞춘 짧은 산책 |
| 위생 관리 | 행동 1회, 키트 재사용. 7일 중 3일 목표 |
| 휴식 | 행동 1회. 피로·긴장 완화. 쉼터나 숨숨집이 있으면 휴식 효과가 더 큼 |
| 간식·캣닢 | 행동 1회, 선택한 소모품 1회분. 정규 식사·활동 점수를 대신하지 않음 |
| 관찰·일지·인벤토리·가이드 | 무료. 관찰 결과를 기록하되 같은 순간의 반복 관찰은 중복 보상 없음 |

오전·오후 각각 2회 행동합니다. 급여·음수 확인·관찰·주문과 사건 열람은 행동 횟수를 쓰지 않습니다. 사건 대응은 선택지에 표시된 행동 비용만 사용하며 무료 선택에는 0 표시를 생략합니다. 같은 돌봄 행동을 하루에 반복하면 효과가 100% → 45% → 15%로 줄어듭니다. 간식 종류를 바꿔도 반복 횟수는 합산합니다.

물 교체 이후 다른 돌봄·급여·시간 이동 시, 수분이 72 미만이고 오늘의 물이 남아 있으며 스트레스가 85 미만이면 자율 음수가 발생합니다. 일지에 실제 음수를 기록하고 그릇의 물도 줄어듭니다. 다음 날에는 새 물을 준비해야 합니다. 물 교체 직후 음수 동작이 자동으로 이어집니다.

### 식사·수분 종료 규칙

식사와 수분은 각각 0~100의 내부 상태입니다. 어느 하나라도 0이 되면 다른 상태가 충분해도 즉시 종료합니다. 종료 이후 급여·물·구매·시간 이동·다음 날 진행으로 되살릴 수 없습니다.

| 시간 진행 | 식사 | 수분 |
|---|---:|---:|
| 급여 시간 경과 | −8 | −6 |
| 돌봄 구간에서 다음 식사로 이동 | −10 | −9 |
| 행동 1회 진행 | −2 | −3 |
| 밤에서 다음 날 아침 | −14 | −16 |

30 이하부터 알림을 표시하고, 15 이하에서는 심한 자세·행동 신호를 표시합니다. 모든 상태 변화 직후 종료 조건을 검사하며 이후 자동 음수 등으로 이미 확정된 종료를 취소하지 않습니다. 경고가 나면 시간을 넘기기 전에 재고·식사·물·실제 음수 기록을 확인하세요.

**세 끼 급여, 상태 감소량, 0에서의 종료는 게임 규칙이며 실제 생존 시간·급여 권장량·의학적 기준이 아닙니다.** 표정이나 관찰 문장으로 특정 질병을 진단하지 않습니다.

### 장난감 반응과 관찰

반응은 무작위 추첨이 아니라 프로필의 자극 선호, 진행 강도, 평소 대비 건강 변화, 피로·스트레스·활동 욕구 및 최근 6번 놀이에서 같은 장난감을 사용한 횟수로 계산합니다. 좋아함·무관심·경계·싫어함에 따라 행동·표정·효과가 달라집니다. 낮고 짧게 진행해도 개체에 맞는 활동이면 충분한 활동 점수를 받습니다.

선택 화면에는 이미 알려진 생활 관리 사항만 보여줍니다. 처음에는 물품별 선호를 모르는 상태이며, 실제 반응을 일지에 쌓으면서 취향을 발견합니다. 한번 좋아했다고 언제나 좋아한다고 단정하지 않습니다.

일지의 시각은 실제 시간이 아닌 게임 시간대입니다. 상태 숫자를 진단 결과처럼 기록하지 않고, 실제 급여·음수·접촉·놀이 반응과 관찰한 신호를 기록합니다. 하루 결산에서는 이전에 관찰한 날과 비교하며, 관찰하지 않은 날의 변화는 미확인이라고 표시합니다.

### 구매와 비용

- 추가 주문 = `Math.round(초기 기준 가격 × 1.10)`. 주문 횟수에 따라 누적 인상하지 않습니다.
- 주문 즉시 잔액과 인벤토리에 반영합니다. 잔액·재고가 부족하면 차감 전에 행동을 막습니다.
- 재사용 물품은 사용해도 남고 중복 주문하지 않습니다. 소모품은 선택한 종류만 차감합니다.
- 비용은 초기 준비비·추가 물품비·상담/병원 등 특별 지출로 나눕니다. 물품은 공개 판매가를 참고한 게임 가격이며, 병원 등 특별 지출은 게임용 예시입니다.
- 초기 준비 후에도 필요한 소모품과 특별 상황에 쓸 돈을 남겨 두어야 합니다.

## 평가

기본 배점은 **35 / 25 / 20 / 10 / 10**입니다. 마지막 상태만 보지 않고 일주일 기록을 사용합니다.

| 항목 | 기준 |
|---|---|
| 기본 돌봄 35 | 정량 식사 21회 50% + 매일 물 교체와 실제 음수 20% + 매일 배변 처리 20% + 3일 위생 관리 10% |
| 성향·정서 25 | 개체에게 맞는 활동의 일별 적합도 50% + 시작 성향 대비 편안함 30% + 휴식/관찰을 한 날 4일 목표 20% |
| 특별 상황 20 | 실제 발생한 사건 대응의 적절성 평균 |
| 준비물 10 | 초기 쇼핑 종료 시 종별 필수 품목 보유율 |
| 예산 10 | 기본 돌봄 충족률에서 과다 급여·반복 간식의 낭비 비율 차감 |

편안함은 일별 `clamp((개체 시작 스트레스 − 결산 스트레스 + 20) / 20, 0, 1)`의 평균입니다. 활동 요구량도 개체별로 다릅니다. 노령·기초 건강 상태 자체를 감점하지 않으며, 필요한 비용을 썼거나 잔액이 적다는 이유로 예산 점수를 깎지 않습니다. 배점을 수정하면 총 100점으로 정규화합니다. 이 점수는 실제 입양 자격이나 동물 건강 판정이 아닙니다.

## 저장과 이어하기

매 선택과 쇼핑 진행을 `localStorage`에 자동 저장합니다. 저장은 브라우저·주소당 시뮬레이션 1개와 체험 진행 1개로 분리되며 새 게임 교체 전 확인합니다. 관찰·일지·발견한 취향·그릇의 물·조기 종료·미해결 사건의 화면 단계·사건별 고유 번호·환경 조정·방 배치를 함께 저장합니다. 쇼핑 팝업·가이드북·탭 숨김 상태에서는 쇼핑 타이머가 멈춥니다.

이전 게임 저장 형식도 가져옵니다. 과거의 실제 음수나 관찰은 추정해서 만들지 않으므로 새 기록에서 직접 확인해야 합니다. 저장소가 막힌 환경에서는 저장 불가를 표시하고 현재 창에서 진행합니다. 다른 주소나 브라우저에서는 저장이 공유되지 않습니다.
