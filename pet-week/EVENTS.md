# 상황 이벤트와 교육 안내 · 4.0

## 플레이 흐름

식사·돌봄·시간 전환에서 조건을 확인하고 모션이 끝난 뒤 사건을 순서대로 표시합니다. 사건이 발생하면 **전체 화면 장면 → 우측 상단 닫기(또는 Esc) → 교육 설명 → 확인/대응 → 방** 순서로 이동합니다. 자동으로 넘기지 않습니다. 설명 화면의 Esc는 사건을 건너뛰지 않으며, 가이드북·추가 주문을 닫으면 미해결 설명으로 돌아옵니다.

설명은 발생 사실, 가능한 이유(건강 사건은 확인할 문제), 실제 대응 선택의 세 항목입니다. 예방·결과를 별도 영역으로 표시하지 않으며, 꼭 필요한 안전 안내는 세 항목에 간결하게 포함합니다. 결과는 선택 뒤 피드백·일지에서 확인합니다. 발생한 피해와 미확인 가능성을 구분합니다. 닫기·읽기는 무료입니다. 실제 대응은 선택지에 표시된 돈·물품·행동 횟수만 사용합니다.

전화로 안내받은 것은 치료 완료로 기록하지 않습니다. 필요한 후속 진료·관찰은 사건 결과와 하루 요약에 남습니다. 게임의 무료 병원 연락과 진료비는 교육을 위한 예시이며 실제 병원 서비스나 비용 기준이 아닙니다.

## 빈도·조건 설정

`dist/event-data.js`의 `CONFIG`를 수정합니다. 새 사건과 체험 챕터는 `dist/scenarios.js`, 실행 순서는 `dist/runtime.js`에서 관리합니다.

| 설정 | 기본값 | 의미 |
|---|---:|---|
| `chance` | 0.62 | 식사·행동·시간 전환의 안전한 체크포인트 추첨 확률 |
| `minPerDay` | 2 | 일반·돌발 일별 목표 하한. 첫 안전 체크포인트와 5번째 이후에 보완 |
| `maxPerDay` | 3 | 일별 목표 상한. 일반 배변은 별도 |
| `cooldownDays` | 3 | 동일 사건의 최소 발생일 간격 |
| `seriousChance` | 0.025 | 하루 한 번만 조건을 만족한 심각 사건군을 추첨할 확률 |
| `minSafeNutrition` / `minSafeHydration` | 32 / 32 | 이 값 이하이면 중단 사건을 미루고 기본 돌봄 기회를 제공 |

1일 차는 안전 조건을 만족하면 새집 적응 장면으로 학습합니다. 동일 사건은 직전 사건과 연속해서 발생하지 않습니다. 심각 사건 후보가 없으면 일반 사건군에서 선택합니다. 이 확률은 현실의 사고·질환 빈도가 아닙니다.

각 사건의 `weight(state, profile, context)`가 가중치를 반환합니다. 0이면 후보에서 제외됩니다. 종·나이·활동 요구·자극 민감도·적응·스트레스·청결·재고·최근 활동·이전 사건과 예방 조정을 반영합니다. 스크래처는 소파 인근 좌표 `(30,69)`와의 거리를 사용하고, 이동 대응은 실제 방 배치에도 반영됩니다. 장난감 실종은 포옹 인형 보유와 최근 사용 2회 이상이 필요합니다. 건강 변화 사건은 최근 이틀의 건강/피로 변화 기록이 필요하고, 큰 병원 지출은 그 조건에 앞선 건강 상담 기록까지 요구합니다. 한 번 빠뜨린 돌봄만으로 병명을 만들지 않습니다.

추가 14개 정의: 첫 식사, 첫 음수, 대변, 소변, 개의 패드 밖 실수, 놀이 요청, 장난감 취향, 창밖 소리, 쉬는 자리, 반복 긁기, 배뇨 패턴 변화, 배뇨 곤란, 걸음 변화, 낡은 물품입니다. 모드별 생리 동작과 체험 전용 사건을 무조건 랜덤 발생시키지 않습니다. 자세한 챕터 목록은 MODES.md를 보세요.

## 사건 추가 방법

`dist/event-data.js`의 `EVENTS`에 고유 `id`를 추가합니다. 기본 속성은 다음과 같습니다.

- `species`, `minDay`, `cooldownDays`, `weight`, 선택적 `serious` / `urgent`: 대상·빈도·진입 조건.
- `image`: 로컬 아틀라스 경로, 2×2 셀 번호, 캐릭터 위치와 너비·표정. `x/y`는 장면의 왼쪽/위에서부터 백분율이며 `y`는 발 위치에 가깝습니다.
- `title`, `description`, `causes[]`, `response`, `prevention`, `consequence[]`: 교육 설명과 발생 사실.
- `effects`, `loss`: **발생 시** 상태 변화·재고 사용 중지. 선택 전에 한 번만 반영됩니다. 손실은 보유 수량까지만 차감합니다.
- `choices[]`: `id`, `label`, `result`, `money`, `cost`, `quality(0~1)`, `effects`, 선택적 `require[]`, `consume`, `flags[]`, `place`, `hospital`, `expenseType`, `followup`.
- `sources[]`, `guide`: 아래 근거 자료 키와 관련 가이드북 항목.

돈·물품·행동이 부족해도 멈추지 않도록 무료·행동 0회로 가능한 적절한 대응을 최소 하나 둡니다. 연습 비용 `cost:1`이면 기존 돌봄 1회의 식사/수분 시간 소모도 적용합니다. 심각한 사건에 방치·임의 약물 투여로 해결하는 선택지를 넣지 않습니다. 자료가 없는 진단이나 이미 관찰하지 않은 부상을 사실로 쓰지 않습니다.

16개 장면은 로컬 PNG 4개에 나누어 저장합니다. 고양이는 `assets/events/pets/{petId}-events-v1.png` 9개, 개는 기존 상태 아틀라스를 겹쳐 표시합니다. 상자 앞면은 같은 로컬 장면의 일부를 앞에 표시해 고양이가 상자 안에 있는 모습을 만듭니다. 생성 프롬프트와 원본 경로는 `ASSET-PROMPTS-EVENTS.md`와 `ASSET-PROMPTS-EVENT-CATS-A/B/C.md`에 있습니다. 실행 중 이미지 생성·검색 API를 사용하지 않습니다.

### 고양이 표정·자세와 움직임

`REACTIONS[eventId]`의 `cat`은 관심→반응→정리의 포즈 번호 3개입니다. 0 앞발 탐색, 1 놀라 물러남, 2 긁기, 3 편안한 웅크림, 4 낮게 숨기, 5 냄새 탐색, 6 무기력·불편함, 7 낯선 공간 경계입니다. `dog`는 기존 개 상태 아틀라스 번호를 사용합니다. `motion`, `x/y/width`, `flip`으로 상황별 움직임과 배치를 조정합니다. 4초 연출 후 그림은 유지하며 자동으로 설명으로 넘어가지 않습니다. 일지에서는 정지 포즈를 표시합니다.

생성 PNG는 그대로 보존하고 각 PNG 옆 JSON의 `frames: [[x,y,width,height], …]`로 안전한 포즈 영역 8개를 지정합니다. JSON 수정 후 `node scripts/build-cat-event-frames.cjs`로 `dist/cat-event-frames.js`를 갱신합니다. 런타임은 가상 384×512 영역 안에 비율을 유지하고 발 위치를 450에 정렬해 앞발·꼬리가 잘리지 않도록 표시합니다. 파일 직접 실행도 지원하도록 별도의 JSON 요청은 하지 않습니다.

선택 개체의 나이·민감도가 움직임 강도에 반영됩니다. 심각한 상태는 일반 사건 표정 대신 기존 상태 포즈를 고정해 신호가 가려지지 않게 합니다. 모션 감소 설정은 마지막 포즈를 표시합니다. 고양이와 배경 로딩 동안 연출을 일시 정지하고 오류 시 안내합니다. 이 모든 시각 처리는 게임 상태·일지·비용을 변경하지 않습니다.

## 상태·저장·정산

`incidents`에 `instanceId`, 발생 날짜·시간대, 화면 단계, 발생 사실, 손실, 선택·지출·상태 변화·후속 확인을 저장합니다. `pendingEvent`와 `activeEvent`는 하나의 미해결 사건만 가리킵니다. 발생과 대응의 일지 기록은 각각 한 번입니다. 버튼은 사건 번호를 함께 전달하므로 오래된 버튼이 다음 사건에 같은 선택 ID로 영향을 줄 수 없습니다.

일지 재열람은 `eventView`와 표시 함수만 사용합니다. 비용·피해·상태 변화 함수는 호출하지 않습니다. 이전 버전 저장의 미해결 사건 4종도 호환 목록으로 유지하며, 재개할 때 새로운 손실을 소급 적용하지 않습니다.

돌봄 물품 주문은 `additional`, 진료와 가정용 물건 교체는 `special`에 기록합니다. 특별 지출의 `type`을 `vet` 또는 `replacement`로 구분합니다. 병원비에 물품의 110% 인상 규칙을 적용하지 않습니다. 잔액·재고·행동 횟수가 부족하면 대응 전체를 거절합니다. 식사나 수분이 0이면 즉시 종료하여 미해결 사건을 중단하고 부활을 막습니다.

사건 점수는 사건 결과의 `quality` 평균입니다. 발생 횟수·파손 금액 자체나 적절한 진료비는 감점하지 않습니다. 무료 환경 조정도 적절하면 같은 점수를 받습니다. 일부 사건의 단기 긴장·청결 변화는 일반 돌봄 상태에도 반영됩니다.
